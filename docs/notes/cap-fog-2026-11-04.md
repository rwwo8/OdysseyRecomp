# Cap Kingdom fog pits look flat bright white (open)

## Seen

The fog in the pits is an even, bright white-blue surface without visible swirls (user's videos, debug frame 2700).

## The program

Fragment program `7269ecb200` (fs hash `e090bac8c2a9209a`, GLSL in `build/glsl/7269ecb200_fs.glsl`) is a 32766-vertex
strip into the scene target. Its inputs (`LARECOMP_DUMP_FSHASH=e090bac8c2a9209a`):

| Slot | Texture | Content |
| --- | --- | --- |
| t0 | 256x256 RG16F | fluid sim (Mario's disturbance): black when undisturbed, plausible |
| t1 | 128x128 RGBA16F | flow / normal map: has data |
| t2 | 512x512 RG16F | ripple texture: near zero, plausible |
| t3 | 1600x900 R16F | linear scene depth (G-buffer target 2): plausible |
| t4 | 256x256x6 RGBA8 cube | environment light, RGBM: colour x 8192 x alpha^4 (`fcb10` = 4, 8192), read at LOD 5 |
| t5 | 1600x900 RGBA8 | G-buffer target 3; its alpha scales the result |
| t6 | 32x32x32 R8 | noise volume (alpha) |

## Findings

- Cube level 0 is dark (mean red about 25/255). Levels 1-5 get steadily brighter (level 5 about 160-240/255), while alpha
  stays low and level (about 19-36/255). Level 5 decodes to roughly 3 against roughly 0.04 for a typical level 0 texel. The
  moon is very bright at level 0 (alpha near 1 means x8192), so a prefiltered low mip may be correct. Not settled.
- No pass draws into this cube during the frame, so it is made at level load or loaded from the stage archive.
- Before update 32 the fog was drawn at 800x450 (see `dynamic-resolution-2026-11-04.md`).

- Scripted walk (see `CLAUDE.md`): the cloud sea beyond the fence is a flat lavender sheet. From the cliff edge
  looking down, the area below is dark, and the visible cloud sea ends in a straight horizontal line. Depth clamp
  (`depth-clamp-2026-11-04.md`) did not change that line.
- The sea is a world-space mesh (`7269ed6200` vertex program: grid positions times a model matrix, displaced by the
  128x128 wave texture), not a screen-projected grid.

## Outcome (update 35)

On the new base (update 35), the same scripted walk shows the cloud sea filling the whole view below the
cliff edges, with no black area and no straight cut (frames 2700, 3600, 4440). The old base's occlusion-query value
(update 34) was one cause. Its other differences from the new base weren't traced further, because the old base was
retired.
